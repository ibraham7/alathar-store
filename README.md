# أثر ستور — متجر مكياج

متجر مكياج إلكتروني خفيف: واجهة متجر + سلة وطلب بالدفع عند الاستلام + لوحة تحكم لصاحب المتجر.

## الملفات

| الملف | الوظيفة |
| --- | --- |
| `index.html` + `js/store.js` | واجهة المتجر، السلة، إرسال الطلب |
| `admin.html` + `js/admin.js` | لوحة التحكم: نظرة عامة، الطلبات، المنتجات، الأقسام، الإعدادات |
| `js/api.js` | الاتصال بـ Supabase (الرابط والمفتاح العام) |
| `js/art.js` | رسومات منتجات المكياج التي تظهر للمنتج الذي لا صورة له |
| `js/logo.js` + `css/logo.css` | الشعار (الختم) مرسوماً داخل الصفحة |
| `css/motion.css` + `js/motion.js` | الحركات والتفاعل |
| `assets/logo.svg`, `assets/logo-mark.svg` | الشعار |
| `supabase/schema.sql` | مخطط قاعدة البيانات كاملاً |
| `supabase/functions/upload-image` | دالة رفع صور المنتجات |

## التشغيل محلياً

الموقع ملفات ثابتة بدون خطوة بناء:

```bash
python -m http.server 4173
```

ثم افتح `http://localhost:4173` للمتجر و `http://localhost:4173/admin.html` للوحة التحكم.

## كيف يعمل

- **المتجر** يقرأ المنتجات والأقسام والإعدادات مباشرة من Supabase بالمفتاح العام (قراءة فقط عبر RLS).
- **الطلب** يمر عبر دالة `place_order` في القاعدة: هي التي تحسب الأسعار وتخصم المخزون، فلا يمكن التلاعب بالسعر من المتصفح.
- **لوحة التحكم** تسجّل الدخول بكلمة سر (محفوظة مشفّرة bcrypt في القاعدة) وتحصل على رمز جلسة صالح 12 ساعة؛ كل عمليات الأدمن دوال تتحقق من هذا الرمز. جداول الطلبات غير قابلة للقراءة من الخارج إطلاقاً.
- **إلغاء طلب** يعيد كمياته للمخزون تلقائياً.
- تغيير كلمة السر من: لوحة التحكم ← الإعدادات.
